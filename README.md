# fuge scoop-bucket

## Add bucket
```
scoop bucket add fscoop https://github.com/Fuge8766/scoop-bucket.git
```

## Install apps
```
scoop install <app_name>
```

## Apps in the bucket
+ [clipman](https://github.com/farzher/clipman): Clipboard manager for Windows. Alternative to Ditto.
+ [glu](https://github.com/boxesandglue/glu): Markdown to PDF. With typographic precision.
