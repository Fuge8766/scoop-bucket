# fuge scoop-bucket

## Add bucket
```
scoop bucket add fscoop https://github.com/Fuge8766/scoop-bucket.git
```

## Install apps
```
scoop install <app_name>
```

## Apps in the bucket
+ [clipman](https://github.com/farzher/clipman): Clipboard manager for Windows. Alternative to Ditto.
+ [glu](https://github.com/boxesandglue/glu): Markdown to PDF. With typographic precision.
+ [warpscout](https://github.com/vernette/warpscout): Find Cloudflare WARP endpoints that work from your network, and see where they exit.
+ [amneziawg windows client](https://github.com/amnezia-vpn/amneziawg-windows-client): This is a fully-featured AmneziaWG client for Windows that uses [Wintun](https://www.wintun.net/). It is the only official and recommended way of using AmneziaWG on Windows.
